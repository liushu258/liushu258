用 C# 学数值方法（五）：牛顿法与非线性方程组#

物理化学平衡、反应动力学、相平衡闪蒸、状态方程物性推导，这些工程问题的数学本质都是非线性方程组。求解它们的核心，是多变量牛顿-拉夫逊法（Newton-Raphson Method）。

工程求解绝非简单套用公式 x(k+1)=x(k)−J−1F(x)x^{(k+1)} = x^{(k)} - J^{-1} F(x)x(k+1)=x(k)−J−1F(x)。盲目的牛顿步很容易跳出物理定义域。摩尔分数超出 [0,1][0, 1][0,1]，绝对温度变成负数，都会引发对数崩溃。在强非线性区域，还会导致迭代振荡甚至发散。

用 C#（.NET 10）实现一个现代工程牛顿求解器。包含数值差分雅可比矩阵、列主元线性子步消元、自适应阻尼线搜索（Backtracking Line Search）和物理定义域限幅保护。实战算例选用 Rachford-Rice 多组分气液平衡方程和强耦合代数方程组。最后剖析工业流程模拟器 DWSIM 的相平衡闪蒸内核。

算法数学推导：多元 Taylor 展开与差分雅可比#

多维非线性方程系统： F(x)=[f1(x1,…,xn)f2(x1,…,xn)⋮fn(x1,…,xn)]=0,x∈RnF(x) = \begin{bmatrix} f_1(x_1, \dots, x_n) \\ f_2(x_1, \dots, x_n) \\ \vdots \\ f_n(x_1, \dots, x_n) \end{bmatrix} = 0, \quad x \in \mathbb{R}^nF(x)=​f1​(x1​,…,xn​)f2​(x1​,…,xn​)⋮fn​(x1​,…,xn​)​​=0,x∈Rn

1. 多元 Taylor 一阶线性化#

在迭代点 x(k)x^{(k)}x(k) 附近进行 Taylor 展开并截断至一阶： F(x(k)+Δx)≈F(x(k))+J(x(k))⋅Δx=0F(x^{(k)} + \Delta x) \approx F(x^{(k)}) + J(x^{(k)}) \cdot \Delta x = 0F(x(k)+Δx)≈F(x(k))+J(x(k))⋅Δx=0 J(x)∈Rn×nJ(x) \in \mathbb{R}^{n \times n}J(x)∈Rn×n 是雅可比矩阵（Jacobian Matrix）。元素为残差函数对未知数的偏导数： Jij=∂fi∂xjJ_{ij} = \frac{\partial f_i}{\partial x_j}Jij​=∂xj​∂fi​​

每一步需要求解线性子方程组： J(x(k))⋅Δx=−F(x(k))J(x^{(k)}) \cdot \Delta x = -F(x^{(k)})J(x(k))⋅Δx=−F(x(k))

2. 向前有限差分近似雅可比#

复杂热力学模型（NRTL、UNIQUAC 或 PR-EOS 等）的解析偏导数推导繁琐，极易出错。工程上普遍用向前数值差分构造雅可比： Jij≈fi(x+ϵj⋅ej)−fi(x)ϵjJ_{ij} \approx \frac{f_i(x + \epsilon_j \cdot e_j) - f_i(x)}{\epsilon_j}Jij​≈ϵj​fi​(x+ϵj​⋅ej​)−fi​(x)​ eje_jej​ 是单位向量。微元扰动量 ϵj\epsilon_jϵj​ 经典取值： ϵj=ϵmach⋅max⁡(∣xj∣,1.0)≈10−8⋅max⁡(∣xj∣,1.0)\epsilon_j = \sqrt{\epsilon_{\text{mach}}} \cdot \max(|x_j|, 1.0) \approx 10^{-8} \cdot \max(|x_j|, 1.0)ϵj​=ϵmach​​⋅max(∣xj​∣,1.0)≈10−8⋅max(∣xj​∣,1.0) 平衡浮点舍入与截断误差。

3. 二次收敛与阻尼保护#

迭代点靠近真根且雅可比矩阵非奇异时，牛顿法具备局部二次收敛性（Quadratic Convergence）： ∥e(k+1)∥≤C⋅∥e(k)∥2\|e^{(k+1)}\| \le C \cdot \|e^{(k)}\|^2∥e(k+1)∥≤C⋅∥e(k)∥2 有效数字每步几乎翻倍。初猜值较远时，标准全步（λ=1\lambda = 1λ=1）极易发散。引入自适应阻尼因子 λ∈(0,1]\lambda \in (0, 1]λ∈(0,1]： x(k+1)=x(k)+λ⋅Δxx^{(k+1)} = x^{(k)} + \lambda \cdot \Delta xx(k+1)=x(k)+λ⋅Δx 利用 Armijo 准则（回溯线搜索）保证残差充分下降： ∥F(x(k)+λΔx)∥<∥F(x(k))∥\|F(x^{(k)} + \lambda \Delta x)\| < \|F(x^{(k)})\|∥F(x(k)+λΔx)∥<∥F(x(k))∥

工程实战案例：多组分气液平衡闪蒸与 Rachford-Rice 方程#

闪蒸罐是两相分离的基础单元操作。参考 Perry 化工手册： CCC 个烃类组分，总流率 FFF，进料摩尔分率 ziz_izi​（∑i=1Czi=1\sum_{i=1}^C z_i = 1∑i=1C​zi​=1）。 在指定温度 TTT 和压力 PPP 下，分离成流率 VVV 的气相（组成 yiy_iyi​）与流率 LLL 的液相（组成 xix_ixi​）。

1. 热力学平衡关系#

  • 总物料衡算：F=V+LF = V + LF=V+L；
  • 组分摩尔衡算：Fzi=Vyi+Lxi(i=1,…,C)F z_i = V y_i + L x_i \quad (i = 1, \dots, C)Fzi​=Vyi​+Lxi​(i=1,…,C)；
  • 相平衡关系：yi=Ki⋅xiy_i = K_i \cdot x_iyi​=Ki​⋅xi​（KiK_iKi​ 为当前 (T,P)(T, P)(T,P) 下的平衡常数）；
  • 相分率定义：气化率 ψ=VF\psi = \frac{V}{F}ψ=FV​，液相率 LF=1−ψ\frac{L}{F} = 1 - \psiFL​=1−ψ。

2. Rachford-Rice 方程推导#

将相平衡代入组分衡算： zi=ψ⋅yi+(1−ψ)⋅xi=xi[1+ψ(Ki−1)]z_i = \psi \cdot y_i + (1 - \psi) \cdot x_i = x_i [1 + \psi (K_i - 1)]zi​=ψ⋅yi​+(1−ψ)⋅xi​=xi​[1+ψ(Ki​−1)] 解得液相与气相组成： xi=zi1+ψ(Ki−1),yi=Kizi1+ψ(Ki−1)x_i = \frac{z_i}{1 + \psi (K_i - 1)}, \qquad y_i = \frac{K_i z_i}{1 + \psi (K_i - 1)}xi​=1+ψ(Ki​−1)zi​​,yi​=1+ψ(Ki​−1)Ki​zi​​ 利用热力学闭合条件 ∑i=1Cyi−∑i=1Cxi=0\sum_{i=1}^C y_i - \sum_{i=1}^C x_i = 0∑i=1C​yi​−∑i=1C​xi​=0，导出 Rachford-Rice 方程： f(ψ)=∑i=1Czi(Ki−1)1+ψ(Ki−1)=0f(\psi) = \sum_{i=1}^C \frac{z_i (K_i - 1)}{1 + \psi (K_i - 1)} = 0f(ψ)=∑i=1C​1+ψ(Ki​−1)zi​(Ki​−1)​=0

3. 数值难点与边界物理限幅#

  • 单调性极佳：导数 f′(ψ)=−∑i=1Czi(Ki−1)2[1+ψ(Ki−1)]2<0f'(\psi) = -\sum_{i=1}^C \frac{z_i (K_i - 1)^2}{[1 + \psi (K_i - 1)]^2} < 0f′(ψ)=−∑i=1C​[1+ψ(Ki​−1)]2zi​(Ki​−1)2​<0，函数严格单调递减，牛顿法理论效率高。
  • 致命极点（Poles）：分母 1+ψ(Ki−1)=01 + \psi (K_i - 1) = 01+ψ(Ki​−1)=0 时存在垂直渐近线。两相共存时气化率受限： ψmin⁡=11−max⁡(Ki)<ψ<ψmax⁡=11−min⁡(Ki)\psi_{\min} = \frac{1}{1 - \max(K_i)} < \psi < \psi_{\max} = \frac{1}{1 - \min(K_i)}ψmin​=1−max(Ki​)1​<ψ<ψmax​=1−min(Ki​)1​ 迭代不加限幅，步长越过极点，会出现摩尔分数为负等非物理结果。

C# 工业级实现：带阻尼与自适应差分的多元牛顿求解器#

核心功能：

  • 多元差分求解器：自动数值求导与列主元线性子系统消元。
  • 自适应回溯线搜索：控制步长，避免发散。
  • 多组分烃类闪蒸：根据 4 组分真实平衡常数计算气化率，反推摩尔分率。
  • 强非线性方程组：求解三元耦合系统。

完整实现代码 (code/05-newton-root/Program.cs)#

using System;
using System.Linq;

// =========================================================================
// 《用 C# 学数值方法（五）：牛顿法与非线性方程组》
// 算例 1：经典三元强耦合非线性方程组
// 算例 2：化工相平衡闪蒸 Rachford-Rice 气液分离 (Perry 化工手册 Sec 13)
// 环境：.NET 10 顶级语句风格
// =========================================================================

Console.WriteLine("===============================================================");
Console.WriteLine(" 1. 经典三元强耦合非线性方程组牛顿求解");
Console.WriteLine("===============================================================");

// 目标方程组 F(x) = 0
Func<double[], double[]> F1 = x => new[]
{
    x[0] + x[1] + x[2] - 3.0,
    x[0]*x[0] + x[1]*x[1] + x[2]*x[2] - 5.0,
    Math.Exp(x[0]) + x[0]*x[1] - x[0]*x[2] - 1.0
};

double[] x0_sys = { 0.5, 0.5, 0.5 };
double[] root_sys = SolveNewtonMultivariate(F1, x0_sys, tol: 1e-7, maxIter: 50);

Console.WriteLine($"\n收敛真解 x = [{string.Join(", ", root_sys.Select(v => v.ToString("F6")))}]");
double[] res_sys = F1(root_sys);
Console.WriteLine($"最终残差范数 ||F(x)||_inf = {res_sys.Select(Math.Abs).Max():E3}");

Console.WriteLine("\n===============================================================");
Console.WriteLine(" 2. 化工热力学闪蒸：四组分烃类 Rachford-Rice 相平衡计算");
Console.WriteLine("===============================================================");

// 模拟进料：乙烷(1)、丙烷(2)、异丁烷(3)、正丁烷(4)
// 进料摩尔分率 z 与当前 T, P 下的平衡常数 K (挥发度自高向低)
string[] compNames = { "乙烷 (C2)", "丙烷 (C3)", "异丁烷 (iC4)", "正丁烷 (nC4)" };
double[] z = { 0.15, 0.35, 0.30, 0.20 };
double[] K = { 4.20, 1.75, 0.74, 0.42 };

// Rachford-Rice 残差函数与导数
Func<double, double> f_RR = psi =>
{
    double sum = 0.0;
    for (int i = 0; i < z.Length; i++)
        sum += z[i] * (K[i] - 1.0) / (1.0 + psi * (K[i] - 1.0));
    return sum;
};

Func<double, double> df_RR = psi =>
{
    double sum = 0.0;
    for (int i = 0; i < z.Length; i++)
    {
        double denom = 1.0 + psi * (K[i] - 1.0);
        sum -= z[i] * Math.Pow(K[i] - 1.0, 2) / (denom * denom);
    }
    return sum;
};

// 物理极点与界限保护
double psi_min = 1.0 / (1.0 - K.Max());
double psi_max = 1.0 / (1.0 - K.Min());
Console.WriteLine($"理论物理气化率边界: ({psi_min:F4}, {psi_max:F4})");

// 牛顿迭代求解气化分率 psi (V/F)
double psi = 0.5; // 初猜 50% 气化
double tol_flash = 1e-8;
int iter_flash = 0;

for (iter_flash = 1; iter_flash <= 30; iter_flash++)
{
    double fVal = f_RR(psi);
    double dfVal = df_RR(psi);

    if (Math.Abs(dfVal) < 1e-12)
        throw new InvalidOperationException("闪蒸导数接近零，牛顿发散。");

    double deltaPsi = -fVal / dfVal;

    // 阻尼回溯：防止跳出 (0, 1) 物理界限
    double lambda = 1.0;
    while ((psi + lambda * deltaPsi <= 0.0 || psi + lambda * deltaPsi >= 1.0) && lambda > 1e-4)
    {
        lambda *= 0.5;
    }

    psi += lambda * deltaPsi;

    Console.WriteLine($"  闪蒸迭代 {iter_flash,2}: psi = {psi,8:F6}, 残差 f(psi) = {fVal,10:E3}, 步长松弛 λ = {lambda:F3}");

    if (Math.Abs(fVal) < tol_flash && Math.Abs(deltaPsi) < tol_flash)
        break;
}

Console.WriteLine($"\n闪蒸计算收敛！平衡气化分率 psi (V/F) = {psi:F6} ({psi * 100:F2} mol% 气相)");

// 计算各相摩尔分率并验证归一化
double[] x_eq = new double[4];
double[] y_eq = new double[4];
for (int i = 0; i < 4; i++)
{
    x_eq[i] = z[i] / (1.0 + psi * (K[i] - 1.0));
    y_eq[i] = K[i] * x_eq[i];
}

Console.WriteLine("\n平衡相组成分布与物料分配:");
Console.WriteLine("组分名称        进料分率 z_i    液相分率 x_i    气相分率 y_i    气液分配 K_i");
Console.WriteLine("---------------------------------------------------------------------");
for (int i = 0; i < 4; i++)
{
    Console.WriteLine($"{compNames[i],-14} {z[i],10:F4}     {x_eq[i],10:F4}     {y_eq[i],10:F4}     {K[i],8:F2}");
}
Console.WriteLine("---------------------------------------------------------------------");
Console.WriteLine($"摩尔分率求和检验: 液相和 Σx = {x_eq.Sum():F6}, 气相和 Σy = {y_eq.Sum():F6} (完全归一)");

// =========================================================================
// 核心通用算法：多元差分牛顿-拉夫逊求解器（带列主元高斯消元与阻尼保护）
// =========================================================================
double[] SolveNewtonMultivariate(Func<double[], double[]> F, double[] x0, double tol, int maxIter)
{
    int n = x0.Length;
    var x = (double[])x0.Clone();

    for (int iter = 1; iter <= maxIter; iter++)
    {
        double[] Fx = F(x);
        double normF = Fx.Select(Math.Abs).Max();

        if (normF < tol)
            return x;

        // 1. 向前数值差分组装雅可比矩阵 J(x)
        double[,] J = new double[n, n];
        double eps = 1e-8;
        for (int j = 0; j < n; j++)
        {
            double orig = x[j];
            double h = eps * Math.Max(Math.Abs(orig), 1.0);
            x[j] += h;
            double[] F_perturbed = F(x);
            x[j] = orig; // 恢复原始值

            for (int i = 0; i < n; i++)
                J[i, j] = (F_perturbed[i] - Fx[i]) / h;
        }

        // 2. 求解线性子步 J · dx = -Fx (带列主元高斯消元)
        double[] rhs = FFx => Fx.Select(v => -v).ToArray();
        double[] dx = SolveLinearSystem(J, rhs);

        // 3. 回溯线搜索（阻尼保护）
        double lambda = 1.0;
        double[] x_next = new double[n];
        while (lambda > 1e-4)
        {
            for (int i = 0; i < n; i++)
                x_next[i] = x[i] + lambda * dx[i];

            if (F(x_next).Select(Math.Abs).Max() < normF)
                break;

            lambda *= 0.5; // 步长减半
        }

        double normDx = dx.Select(Math.Abs).Max();
        Console.WriteLine($"  系统迭代 {iter,2}: x = [{string.Join(", ", x.Select(v => v.ToString("F4")))}], ||F||_inf = {normF:E3}, λ = {lambda:F3}");

        x = x_next;
        if (normDx < tol && normF < tol)
            return x;
    }

    throw new TimeoutException($"多元牛顿法在 {maxIter} 步内未收敛。");
}

// 列主元高斯消元求解线性子系统
double[] SolveLinearSystem(double[,] A, double[] b)
{
    int n = b.Length;
    var M = new double[n, n + 1];
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < n; j++)
            M[i, j] = A[i, j];
        M[i, n] = b[i];
    }

    for (int col = 0; col < n; col++)
    {
        int maxR = col;
        double maxV = Math.Abs(M[col, col]);
        for (int r = col + 1; r < n; r++)
        {
            if (Math.Abs(M[r, col]) > maxV)
            {
                maxV = Math.Abs(M[r, col]);
                maxR = r;
            }
        }

        if (maxR != col)
        {
            for (int c = col; c <= n; c++)
                (M[col, c], M[maxR, c]) = (M[maxR, c], M[col, c]);
        }

        for (int r = col + 1; r < n; r++)
        {
            double factor = M[r, col] / M[col, col];
            for (int c = col; c <= n; c++)
                M[r, c] -= factor * M[col, c];
        }
    }

    var x = new double[n];
    for (int i = n - 1; i >= 0; i--)
    {
        double sum = 0.0;
        for (int j = i + 1; j < n; j++)
            sum += M[i, j] * x[j];
        x[i] = (M[i, n] - sum) / M[i, i];
    }
    return x;
}

工业实践：DWSIM 中的限幅与阻尼保护#

开源流程模拟器 DWSIM 的闪蒸模块（FlashAlgorithms/NestedLoops_v2.vb 与 MathOps/Brent.vb），对牛顿法施加了多重防御屏障：

  1. 硬限幅与极点保护： 预先计算理论物理极点 ψmin⁡,ψmax⁡\psi_{\min}, \psi_{\max}ψmin​,ψmax​。一旦牛顿步跨越边界或越出 [0,1][0, 1][0,1]，立刻强制截断（Clamp）至安全区间内（例如 ψnew=0.5(ψold+ψbound)\psi_{\text{new}} = 0.5(\psi_{\text{old}} + \psi_{\text{bound}})ψnew​=0.5(ψold​+ψbound​)）。
  2. 自动回退（Fall-back to Brent）： 当发生连续 3 次振荡，或导数接近奇异。求解器无缝降级切换至 Brent 算法（结合二分、割线与逆二次插值）。带括号区间的绝对收敛特性，能避免死循环导致程序崩溃。
