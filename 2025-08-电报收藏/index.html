  • 08-10 12:36 🧀 | 分享一些 Vibe Coding 心得
    Vibe coding 本质是组织上下文，让 LLM 给出更优答案。
    1. 选模型：能用最好的就别退而求其次，如 Claude 4 优于 3.5，o3 优于 4o。核心是熟悉少量顶尖模型。
    2. 理解原理：Cursor、Claude Code、Augment Code 其实都是在 LLM 上做 tool calling，差别在于上下文管理和工具组合。
    好结果 = 正确上下文 + 正确工具调用
    Cursor 偏向 RAG 补充上下文，可能读不全代码；Claude Code 更倾向直接读原始代码。遇到效果差时，先检查上下文或工具是否合适。
    实用技巧：
    • 写代码前，先让 AI 收集上下文
    • 用 vibe-doc 文件夹分功能记录
    • 让 AI 完善需求，及时开新对话（内容较长，已压缩）
